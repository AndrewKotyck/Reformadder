# Reformadder

A config-driven Python engine that reshapes **wide** spreadsheets into **long**, analysis-ready tables.

Many exports (survey tools, finance systems, BI tools) spread one measurement across hundreds or thousands of columns and pack the meaning of each value into the column header: `dAllRatings_R16829r1022` holds a subject company, a competency and a rating. Pivot tables, Power BI and pandas want the opposite: one row per value, with each dimension in its own column.

Reformadder does that reshaping from a JSON config file. Supporting a new layout means writing a new config, not new code.

In production it turned a **14-row × 8,693-column** survey export into a **3,269-row × 9-column** table.

```
WIDE (one row per respondent)
uuid | dQ1r7 | Q1r1 | ... | dAllRatings_R60001r1022 | dAllRatings_R60001r1005 | ... (8,693 cols)

LONG (one row per rating)
Response Code | Respondent Company Code | First Name | ... | Subject Company Code | Competency Code | Rating
```

## How it works

```
 .xlsx ──► find each section's columns ──► decode headers + values ──► filter + merge ──► build level tree ──► flatten ──► .xlsx
            (searchparser.py)              (internalfunction.py)       (reformatter.py)   (datatypes.py)      (reformatter.py)
                     ▲                              ▲                          ▲                  ▲                 ▲
                     └──────────── reformadder_config.json controls every stage ───────────────────────────────────┘
```

1. **Load**: `excelporter.py` reads the first sheet; row 1 is the header row.
2. **Locate columns by pattern**: each config section names its columns with a small pattern language, so columns are found by name, not position. `dAllRatings~` finds all 3,774 rating columns without listing them.

   | Pattern  | Matches                                   |
   |----------|-------------------------------------------|
   | `Q1r1`   | exactly `Q1r1`                            |
   | `Q3~`    | headers starting with `Q3`                |
   | `~OALL`  | headers ending with `OALL`                |
   | `$Q8~`   | everything *except* headers starting with `Q8` |

3. **Decode with a nested function language**: each section's `function` string is parsed once into a tree of function nodes, then evaluated for every row. `<header>` and `<value>` stand for the section's headers and cells.

   ```
   split(between(<header>,_,r), between(<header>,r,~), <value>)
     dAllRatings_R60001r1022 = 4   →   (R60001, 1022, 4)
   join(; ,cross(split(between(<header>,Q3,~),<value>)))
     Q3PRTPCM=0  Q3PRMTMR=1  Q3PRQATT=1   →   "PRMTMR; PRQATT"
   ```

   Available functions: `between`, `split`, `cross`, `join` (`lookup` is in progress).

4. **Filter and merge**: `target` rules drop unusable answers (`<value>$99`, `<value>$Cannot Rate`) or columns. `merges` stacks one section onto another, such as overall ratings with a different header shape.
5. **Build a level tree**: each section has a `group` level (here 1 = company → 2 = respondent → 3 = ratings). Each row becomes a small chain. Rows that share a top-level key are merged, so respondents from the same company are grouped together even if their rows are far apart.
6. **Flatten**: a recursive generator walks from the root to every bottom-level value and emits one row per path, with columns in `name_order`.

The engine itself knows nothing about surveys, so the same code also handles other shapes, such as a store × month sales sheet with `region → store → (measure, month, amount)`.

## Run it

Requires Python 3.12+ and openpyxl. Windows only for now (output paths are built with `\`).

```powershell
pip install -r requirements.txt
copy "sample_data\sample survey export.xlsx" .   # main.py looks for .xlsx and .json files in its own folder
python main.py
```

Pick `reformadder_config.json`, then the sample export. Press Enter to save the output next to the input with ` - reformatted` added to the name. Compare it with `sample_data/sample survey export - reformatted.xlsx`.

To build a standalone Windows executable: `pyinstaller Reformadder.spec`. Put the exe next to a config file and the data to reformat.

## Sample data

`sample_data/` holds an anonymized copy of a real export, generated by `tools/make_sample_data.py`:

- names, emails, phones, job titles, company names and IDs are replaced with made-up values
- company and subject-company codes are remapped consistently, so grouping still works
- open-ended comments are replaced with placeholder text
- every other answer column is shuffled across respondents, so the values look realistic but no row is a real person's answers
- the codebook sheet is removed

## Performance

Profiling with `cProfile` showed that about 85% of runtime was spent in the flattening step. `yield_deepest` used a mutable default argument (`valuenodes: list = []`). Python creates that list once and reuses it forever, so it grew with every node visited, and each output row re-read every earlier row's values. That made the run time quadratic. Passing each branch its own path fixed it:

| 1,000,000 values (400 rows × 2,500 cols) | Time  |
|------------------------------------------|-------|
| before                                   | 16.2 s |
| after                                    | 4.2 s  |

The output is identical before and after. The next bottleneck is decoding the same headers again for every row; caching the decoded headers would remove most of it.

## Known limitations

- All dimensions must be in a single header row on the first sheet.
- Only one fanned-out (multi-value) section per group level.
- Only the top level merges duplicate keys.
- Values are kept as text; type casting and lookup tables are on the roadmap.
- Known bugs:
  - with fewer than 10 output rows, the progress counter in `reformat()` divides by zero
  - a section with exactly one `<value>` filter fails (`index_lists_intercept` returns the outer list)
  - on flat (single-list) values, only the last `<value>` filter is applied

## Project layout

```
main.py                  console menu: pick a config and a data file
reformatter.py           Engine (per-row evaluation, tree merge, flattening) + Reformatter
datatypes.py             HolderNode / ValueNode tree
internalfunction.py      function-string parser and per-section column selection
functiontypes.py         between / split / cross / join / lookup
searchparser.py          ~ and $ header pattern matching
excelporter.py           .xlsx and .json load/save
reformadder_config.json  config for the survey export
tools/make_sample_data.py  anonymizer used to create sample_data/
```
